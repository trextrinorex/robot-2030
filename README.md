# ROBOT 2030

**A Scenario Investigation of Humanoid Machines in Ordinary Places**

This is an original interactive research report examining the conditions under which humanoid robots could become economically useful and scalable in workplaces, factories, warehouses, and (separately) homes around 2030. It is explicitly a scenario analysis, not a prediction.

## Core Question

What happens if humanoid robots become economically useful, technically capable, and scalable enough to move from demonstrations and pilot programs into ordinary workplaces by around 2030?

## Principles

- Evidence over hype. Company claims are labeled as such.
- Explicit uncertainty categories: DOCUMENTED, MODELED, SCENARIO, ASSUMPTION, SPECULATIVE.
- Multiple coherent futures rather than a single base case with probabilities.
- Transparent unit economics and assumption tracking.
- Original visual and interaction design (industrial / engineering language, not generic AI aesthetics).

## Running Locally

```bash
cd robot-2030
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
